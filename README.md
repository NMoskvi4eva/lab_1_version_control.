# lab_1_version_control.
# Лабораторна робота №1. Робота з версійним контролем (Git)

Цей репозиторій створено для виконання навчальної лабораторної роботи №1 з теми **«Робота з версійним контролем (Git)»**.

**Призначення репозиторію:**
* Опанування базових навичок роботи з розподіленою системою контролю версій Git та сервісом GitHub.
* Демонстрація практичного виконання основних команд: клонування, фіксація змін (commit), робота з індексом та відправка коду на віддалений сервер (push).
* Публікація та надання публічного доступу до навчального проєкту.
